Términos y condiciones de uso

Última actualización: 07/08/2026

Estos términos y condiciones son los encargados de regular tu uso del sitio web de ACH Imports Ltd("Este sitio web"). Al acceder a este sitio web aceptas estar sujeto a los siguientes términos. Si no estás de acuerdo con estos términos, no debes usar el sitio web. ACH Imports Ltd ("nosotros", "nuestra") proporcionamos este sitio web solo para información general. Este sitio web está dirigido a proveedores, cultivadores y socios que deseen aprender sobre nuestro negocio y contactarnos respecto a posibles relaciones comerciales

1. Términos de uso aceptable

Debes aceptar no usar el sitio web para los siguientes propósitos:

  • Para cualquier propósito malicioso o fraudulento
  • Presentar información engañosa, falsa o dañina
  • Interferir o interrumpir el sitio web o su entorno de alojamiento
  • Intentar obtener acceso no autorizado a cualquier parte del sitio web
  • Raspar, recopilar o extraer datos, contenido o imágenes sin permiso
  • Usar herramientas automáticas, bots o scripts para interactuar con el sitio web o su formulario de contacto

Podemos reservarnos el derecho de restringir y bloquear el acceso a cualquier usuario que viole los términos establecidos.

2. Términos de precisión informativa

El contenido de este sitio web se proporciona solo con fines informativos generales. Nuestro objetivo es mantener la información precisa y actualizada, sin embargo, no se puede garantizar lo siguiente:

  • Integridad
  • Precisión
  • Confiabilidad
  • Idoneidad
  • Disponibilidad

Cualquier confianza que pongas en la información es estrictamente bajo tu propio riesgo. Podemos actualizar, modificar o eliminar contenido en cualquier momento sin previo aviso.

3. Términos de compromiso comercial

El sitio web no constituye:

  • Una oferta para comprar productos
  • Una garantía de compromiso comercial de nuestra parte
  • Una representación vinculante de las especificaciones del producto
  • Un compromiso contractual de cualquier tipo

Todas las discusiones y decisiones comerciales ocurren fuera de línea, mediante comunicación directa con ACH Imports Ltd y su equipo administrativo.

  • Copiar

  • Volver a publicar

cualquier parte del sitio web sin permiso escrito explícito previo.

El sitio web puede contener enlaces a sitios web externos, cultivadores o proveedores. Estos enlaces se proporcionan solo por conveniencia. No somos responsables de:

  • El contenido del sitio web externo
  • La exactitud de la información externa almacenada en o dentro de estos sitios
  • Cualquier pérdida o daño que surja por visitar los enlaces externos

Accedes a sitios web de terceros bajo tu propio riesgo

6. Términos sobre el formulario de contacto y las consultas

Si envías información a través de nuestro formulario de contacto:

  • Aceptas que la información que proporcionas es precisa
  • Aceptas no enviar mensajes spam, maliciosos o automáticos
  • Aceptas que enviar un formulario no crea ninguna obligación comercial de nuestra parte

Nos reservamos el derecho de ignorar, rechazar y bloquear cualquier envío que parezca violar las declaraciones anteriores

7. Términos sobre privacidad y manejo de datos

Nuestro manejo de los datos personales está regido por nuestro política de privacidad, lo que explica:

  • Qué datos recopilamos
  • Cómo lo usamos
  • Cómo se almacena
  • Tus derechos según la ley de protección de datos del Reino Unido y el GDPR

En la máxima medida permitida por la ley, ACH Imports Ltd no será responsable de ninguno de los siguientes:

  • Pérdida directa, indirecta o consecuente

  • Pérdida de ganancias
  • Daños derivados del uso del sitio web
  • Dependencia de la información del sitio web
  • Problemas causados por servicios de terceros o proveedores de alojamiento

Aunque hacemos nuestro mejor esfuerzo, no podemos garantizar que el sitio web:

  • Siempre disponible

  • Sé seguro
